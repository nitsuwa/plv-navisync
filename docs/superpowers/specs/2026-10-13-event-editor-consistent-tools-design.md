The user approved all eight proposed improvements: clear placement mode, ghost/validity feedback and repeat placement, shared sizing rules, approximate realistic scale, shared inspector, more canvas space, uncluttered selection affordances, and save/layout feedback. The subsequent explicit instruction replaces exact calibration: use the existing buildings/doors as a visual reference; no verified measurements or meter claims are required.

Keep the existing PLV navy/light/dark design, typography and asset artwork. Placement mode is recognizable on desktop through a crosshair across all actual hit targets, a pointer badge and ghost footprint; a persistent placing strip also works on touch. Sizes remain approximate map units, not meters.

Layout issue actions select and frame the affected objects in the current view. Physical footprint visuals remain truthful while control hit areas remain usable at phone sizes.
