PLV NAVISYNC – SMART CAMPUS NAVIGATOR

PROJECT OVERVIEW

Create a modern Smart Campus Navigator for Pamantasan ng Lungsod ng Valenzuela (PLV).

The platform should help students, faculty, visitors, and staff navigate the campus efficiently through a centralized interactive map.

The map should be the core of the entire system.

Instead of spreading information across many pages, all buildings, offices, facilities, events, accessibility information, emergency information, and navigation features should be accessible directly through the map.

The system should initially support one campus (PLV Main Campus) while being designed to support multiple campuses in the future through an advanced administrative Map Builder.
