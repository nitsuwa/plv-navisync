nteractive Campus Map

The Map should be the main feature and centerpiece of the entire platform. Almost every important interaction should happen here instead of being separated into different pages.

The map should occupy most of the screen and feel similar to Google Maps, with a large interactive map on the left and a Smart Information Panel on the right. Remove the current building list and replace it with a contextual information panel that changes depending on the selected building or location.

When no building is selected, the Smart Information Panel should display the search bar, recent searches, and popular destinations such as the Registrar, Cashier, Library, Admissions Office, Gymnasium, and Student Services.

When a building or marker is selected, the Smart Information Panel should display the building photo, name, description, category, office hours, contact information, departments, facilities, accessibility information, emergency information, current operational status, and QR code. It should also provide action buttons such as Get Directions, Share Location, Save Location (Student only), and Report Issue (Student only).

The map should continue supporting Smart Search, turn-by-turn navigation, accessibility routes, emergency evacuation routes, visitor-friendly routes, event markers, QR building information, zoom controls, layer controls, and current location detection.

Campus events should no longer exist as announcements on a separate page. Instead, administrators should place event markers directly on the map. Selecting an event should display the event poster, title, description, venue, organizer, date, time, and a button to navigate to the event location.

Accessibility features such as wheelchair-accessible routes, elevators, ramps, accessible entrances, accessible restrooms, and braille signage should remain available through a dedicated Accessibility Layer.

Emergency features should remain available through an Emergency Layer that displays emergency exits, evacuation routes, assembly areas, security offices, clinics, first aid stations, fire extinguishers, and emergency contact numbers.

Integrate Issue Reporting into the Map

Remove the standalone Reports page completely.

Issue reporting should become a built-in feature of the interactive map.

Students should be able to click any building or any location on the map and select Report Issue from the information panel. This should open a clean modal instead of redirecting to another page.

The report form should include the following fields:

Issue Type
Description
Photo Upload

The selected map location should automatically be attached to the report so students do not need to manually enter the location.

Common issue types should include Broken Light, Flooded Area, Damaged Property, Blocked Walkway, Safety Hazard, Facility Problem, and Other.

After submission, students should receive a confirmation message and be able to monitor the report's status from their profile dashboard.

Help Center

The Help Center should replace the old Reports page and become the main support page for the platform.

The page should follow the same visual style as the Home page by starting with a modern hero section that introduces the Help Center and encourages users to seek assistance.

The content should flow vertically in a single-column layout instead of using multiple columns or complicated card layouts. Each section should naturally lead into the next to create a simple and easy-to-follow experience.

The page should contain only three main sections:

AI Campus Assistant

The first section should feature a large modern AI chat interface where users can ask questions about campus navigation, buildings, offices, classrooms, facilities, accessibility, and events.

Suggested questions such as "Where is the Registrar?", "How do I get to the Library?", "Where is Room 305?", and "What events are happening today?" should be displayed as clickable suggestions.

Guest users should have a limited number of AI questions per day, while logged-in students should have unlimited access.

Contact / Inquiry Form

Below the AI Assistant should be a simple inquiry form where users can contact the university regarding navigation, academic concerns, technical issues, or general questions.

The form should only contain Name, Email, Category, Subject, and Message fields.

Frequently Asked Questions

At the bottom of the page, include a clean accordion-style FAQ containing only the most common questions. Avoid creating long documentation pages.

Guest User Experience

Guests should have access to almost the entire platform without creating an account.

Guests should be able to browse the Home page, use the interactive campus map, search for buildings and facilities, generate navigation routes, view building information, explore accessibility routes, use Emergency Mode, view campus event markers, scan building QR codes, and use the AI Campus Assistant with limited daily questions.

Guests should not be able to save favorite buildings, save routes, report campus issues, receive personalized notifications, access the student dashboard, or track reports and inquiries.

Whenever a guest attempts to use one of these features, display a friendly sign-in prompt encouraging them to log in using their PLV account.

Student User Experience

Students should continue using the exact same interface as guests after logging in. The layout should not change. Instead, additional features should become available throughout the system.

Students should be able to save favorite buildings, save favorite routes, save frequently visited locations, report issues directly from the interactive map, track the status of submitted reports, submit inquiries through the Help Center, receive personalized campus notifications, use the AI Campus Assistant without limits, and access a personal profile dashboard.

Student Profile Dashboard

Instead of displaying a simple profile page, create a lightweight Student Dashboard that focuses on personalization.

The dashboard should contain Profile Information, Favorite Buildings, Favorite Routes, Recent Searches, My Reports, My Inquiries, Notification Preferences, and Account Settings.

The overall experience should remain clean, modern, and minimal, ensuring that the interactive campus map continues to be the primary focus of the platform while the student dashboard serves as a convenient place to manage personal activity and saved information.
